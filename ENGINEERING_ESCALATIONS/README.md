---

## When to File Here

Per `.kilo/rules/crew-protocols.md` Rule 8 and every Crew Order's Sarek Escalation Clause:

**File an escalation when O'Brien is blocked for 3 consecutive attempts on any single step.**

Do not continue guessing. Do not invent workarounds. File here and stop.

---

## Filing Format

Filename: `YYYY-MM-DD-orderNNN-short-description.md`

Example: `2026-07-03-order006-outbox-service-worker.md`

```markdown
# Escalation — ORDER NNN
**Date:** YYYY-MM-DD
**Filed by:** O'Brien
**Order:** CREW-ORDER-NNN
**Step:** [exact step or milestone number from the Crew Order]

## What I Was Trying to Do
[One paragraph — what the step requires]

## What I Tried (3 attempts)
1. [attempt 1 — what I did, what happened]
2. [attempt 2 — what I did, what happened]
3. [attempt 3 — what I did, what happened]

## Error Output
[paste exact error message or unexpected behaviour]

## What I Think the Problem Is
[O'Brien's best assessment — even if uncertain]

## Impact
[What this blocks — which milestones, which subsequent orders]

**O'Brien — awaiting Scotty**
```

---

## Response Protocol

**Scotty** (Claude API / escalation engineer) reads the file, investigates, and appends a `## Scotty Response` section to the same file with the resolution or further diagnosis.

**Spock** monitors this folder during Bridge sessions and surfaces unresolved escalations to the Captain.

**O'Brien** resumes work only after Scotty's response confirms the path forward.
